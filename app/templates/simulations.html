Compare how storage allocation and disk scheduling affect the same repeatable workload.

These are simulated time units, not seconds. Moving one box costs 1 unit; each block request has 1 unit fixed latency; transferring one 100-unit block costs 1 more unit at the default rate. Shipment operations arrive at different times during the first 100 simulated units.
What is an I/O operation?

One operation is a shipment-level READ or WRITE. It creates one disk request for every block in that shipment, so a 250-unit shipment creates three requests. Arrival time is when an operation joins the simulated request queue; it is not real elapsed time.
